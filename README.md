**Milo's Garden** — a warm, hand-drawn-feeling spot-the-difference game starring Milo, an orange cat. Compare two side-by-side pictures of the same scene and click everything that changed: 3 rounds (Garden Morning, Beach Sunset, Cozy Kitchen), 7 differences each, 90 seconds a round, +100 per find, −20 per wrong click, hints, pause, and synthesized Web Audio sounds. Every picture is drawn procedurally on canvas at run time — no image files, no network requests, fully offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. `?shot=start&seed=1`, `?shot=play&seed=1` and `?shot=end&seed=1` freeze the game in its title, mid-round and round-clear states for screenshots.
